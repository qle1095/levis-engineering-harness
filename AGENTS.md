# Levi's engineering harness

This repo is a docs/skills harness, not an application.

For a pipeline that runs through, name or invoke [`orchestrator-e2e`](.agents/skills/orchestrator-e2e/SKILL.md).

For a pipeline that stops after each phase and explains it with explain-to-levi before the next, name or invoke [`orchestrator-learning`](.agents/skills/orchestrator-learning/SKILL.md). It writes a run record when that phase tables cleanly.

When explaining anything to Levi, follow [`explain-to-levi`](.agents/skills/explain-to-levi/SKILL.md).

See [README.md](README.md), [STANDARDS.md](STANDARDS.md), and `.agents/skills/`.
